# GTALab — atualizações

Este repositório guarda **somente os instaladores do GTALab** (Windows x64), publicados em
[Releases](../../releases). O GTALab consulta a versão estável mais recente ao abrir e oferece a atualização;
nada é instalado sem o clique do usuário.

- Cada versão tem o instalador `GTALab-Setup-X.Y.Z.exe` e o arquivo `SHA256SUMS.txt` com o código de conferência.
- O GTALab baixa o instalador, confere o SHA-256 e só então instala por cima da versão atual
  (mesma instalação, configurações, contas e vídeos preservados).
- Instalação manual: baixe o `GTALab-Setup-X.Y.Z.exe` da versão mais recente e execute.

O instalador ainda não tem assinatura digital (certificado de código). Por isso o Windows SmartScreen pode avisar
na primeira instalação: clique em "Mais informações" e em "Executar assim mesmo" somente se o arquivo veio daqui.
